# PT Backup

Бэкап проектов Pro Tools на сетевой диск (SMB) и распаковка обратно. macOS, Apple Silicon.

- **Бэкап:** WAV → FLAC без потерь (чанки BWF сохраняются), бэкапы сессий — в один архив zstd, дубликаты от 100 МБ — ссылками,
  отправка rsync; на сервер уходит только новое и изменённое (старые версии остаются с датой в имени).
- **Daily:** ежедневно по расписанию, локальные файлы не трогает; неизменённые сессии пропускаются по отпечаткам.
- **Архивация:** бэкап, сверка копии на сервере и удаление локальной.
- **Разархивация:** копия с сервера, FLAC → WAV байт в байт, сборка дубликатов; аудио и видео сессии из других папок проекта
  находятся по ID Pro Tools.
- **Окно:** очередь заданий, история с логами, расписание по тегам Finder, иконка в строке меню, автообновление.

## Установка

Скачайте `PTBackup-<версия>.zip` из [Releases](../../releases/latest), распакуйте в «Программы».
При первом запуске macOS спросит разрешение (программа подписана локально): правый клик → «Открыть»
или `xattr -cr "/Applications/PT Backup.app"`. Программа сама ставит движок в `/usr/local/bin`.

Нужно: Python 3.12 (`~/.pyenv/versions/3.12.2` или системный), `brew install flac zstd rsync`.
Для рабочих копий видео — утилита `mix_prep` в `/usr/local/bin`; для поиска видео сессий — программа «Reaper to Pro Tools».
Сервер и пользователь — в начале `engine/pt_backup.py` (`SMB_HOST`, `SMB_USER`); пароль — в связке ключей macOS.

## Разработка

